## 排障顺序

1. 有线网卡 Disconnected：先看供电、网线、转接器、链路灯；没有链路时不先猜 IP。
2. SSH 通、管理页不通：核对网关进程、监听端口和日志。
3. JPEG 无图：核对相机网段、凭据、ONVIF、GStreamer/MPP 插件及 camera.log。
4. 无点云：核对接口/源地址、雷达 .0.101 控制口、UDP、xt_radar.log。
5. 程序运行但 PC 收不到：核对端点 bind、电脑有线 IP、SN 和实际主题。
6. 8080 有页但独立 H.264/点云预览无画面：检查可选 vizd、FFmpeg、URL、UDP 镜像；不能归因协议流一定失败。
7. 标定漂移：先核对轴版本、机械固定、单帧配对和真实延迟；不要直接缩放点云或硬改外参。

不要将真实相机 URL、camera.env、SSH 密码、原始设备工厂文件或未经脱敏的日志提交到源码仓库。
